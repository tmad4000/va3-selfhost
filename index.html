VA3 self-host kit · v0.28.1

Your own hands-free voice assistant, on your own server.

Voice Assistant 3 (VA3) is a voice-first assistant built for talking while you drive or walk. The VA3 Drive iPhone app records while the screen is locked, holds what you say through signal drops, and plays replies aloud. This kit runs the server half on a small cloud VM you control.

What you get

  • A private voice conversation server: speech in, a short spoken answer out, with persistent memory of what you ask it to remember.
  • Store-and-forward: speak with no signal and the phone sends it when you're back online.
  • One small dependency-free Node.js process, a systemd unit, and HTTPS through Tailscale (private) or your own domain.
  • Revocable per-device tokens, so a lost phone is one command away from locked out.

Not included: agent automation, browsing or computer control. Those features rely on infrastructure that isn't part of this kit and are disabled in self-host mode.

Privacy model

Your server

Runs on a VM in your own cloud account. Conversations and memory stay in its data directory.

Your key

Uses your own OpenAI API key, stored in a root-only file on your server. You see and pay for all usage.

Your data

No telemetry, no callbacks. Nothing goes to whoever shared this kit, and it ships with none of their keys or data.

Requirements

  • A Linux VM (Ubuntu 24.04 LTS; 1 vCPU / 1 GB is plenty) on any provider, about €4–15/month.
  • An OpenAI API account with billing on. Typical casual use costs a few dollars a month; set a budget limit.
  • An iPhone running VA3 Drive (TestFlight).
  • A free Tailscale account (recommended), or a domain you can point at the VM.
  • Comfort running commands over SSH. Setup is copy-paste and takes about one sitting.

Setup in five steps

  1. Create a VM and install Node.js 22Ubuntu 24.04 on Hetzner, GCP or any provider.
  2. Download and verify the kitCheck SHA256SUMS, extract to /opt/va3, and create a dedicated va3 user.
  3. Initialize and issue a phone tokennode bin/va3-setup.mjs init, then issue. The token is shown once.
  4. Run it as a servicesystemd unit with your OpenAI key in a 0600 EnvironmentFile, listening on loopback only.
  5. Add HTTPS and connect the phonetailscale serve (or Caddy), check /api/drive/hello, then tap Verify and connect in the app.
